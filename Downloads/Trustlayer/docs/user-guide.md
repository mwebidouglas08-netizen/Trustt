# User guide (draft)

## Buyers
1. Register and confirm email.
2. Create a transaction, invite seller.
3. Review agreement carefully, fund escrow from your wallet (you need SOL for fees).
4. After delivery, accept and release, or open a dispute with evidence.

## Sellers
1. Accept invitation and verify wallet.
2. After buyer funds (visible on-chain), submit delivery/completion evidence.
3. Respond to disputes if opened.

Always verify network (devnet/mainnet) and token mint shown in-app before signing.
